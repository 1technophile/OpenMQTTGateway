# Supporting the project

If you like the project, you can help in different ways. Choose what fits you best.

# Give time and knowledge

  • Help other users in the community (opens new window).
  • Share logs, payload samples, or how-to posts that unblock others.

# Contribute code or docs

  • Follow the Development contributions guide to open a PR.
  • Improve docs or examples if you spot unclear steps.

# Financial support

  • Purchase the Theengs mobile application (opens new window) or the Theengs plug (opens new window).
  • Buy devices or parts via the compatible web site (opens new window) (affiliate links help the project).
  • Sponsor the project developers (opens new window).
  • Make a video or blog article about what you built with OpenMQTTGateway (opens new window) and share it.

Support open-source development through sponsorship and gain exclusive access to our private forum. Your questions, issues, and feature requests receive priority attention, plus you'll see the roadmap early.
